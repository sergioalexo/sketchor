# Local sample files (template)

Copy this file to `docs/local-samples.md` (gitignored) and fill in the paths on
your machine. Plans refer to these names instead of real paths so that no
third-party file names, job numbers or folder layouts end up in the public repo.

| Name | What | Path |
|---|---|---|
| `PROD_FILES` | Real-world DXF folder for the X-03 import coverage sweep (`docs/cad-fidelity-plan.md`) — thousands of files, read in place | `<path>` |
| `LARGE_STEP` | A 50+ MB multi-part STEP assembly for the large-file checks (`docs/large-step-and-up-axis-plan.md`) | `<path>` |

Never copy these files, or anything derived from them, into the repo.
